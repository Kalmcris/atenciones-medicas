# Sistema de Atenciones Médicas

Aplicación web sencilla para la gestión de atenciones médicas, desarrollada para la asignatura de Base de Datos de Ingeniería Civil Informática, Universidad del Bío-Bío.

## Funcionalidades

- Registro, consulta y modificación de pacientes.
- Registro, consulta y modificación de médicos.
- Gestión de atenciones médicas.
- Consulta de atenciones vigentes.

## Tecnologías

- Python y Flask
- PostgreSQL
- psycopg2
- HTML, CSS y JavaScript

## Ejecución

1. Instalar las dependencias con `pip install -r requirements.txt`.
2. Crear una base de datos en PostgreSQL.
3. Ejecutar el archivo `database.sql`.
4. Configurar las variables de entorno `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER` y `DB_PASSWORD`.
5. Ejecutar `python app.py`.
6. Abrir http://127.0.0.1:5000.
